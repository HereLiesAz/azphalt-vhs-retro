# VHS Retro

Authentic VHS decay — scanlines, chroma bleed, edge wobble and tape noise that drift over time like a worn cassette.

An [azphalt](https://github.com/HereLiesAz/azphalt) extension for
[Guillotine](https://github.com/HereLiesAz/Guillotine).

- **Package id** — `com.hereliesaz.azphalt.vhs-retro`
- **Version** — 1.0.0
- **Kind** — asset (ISF fragment shader)
- **Tags** — `shader`, `distortion`, `vhs`, `retro`, `analog`, `nostalgic`, `one-click`

## Controls

| Parameter | Label | Range | Default |
| --- | --- | --- | --- |
| `amount` | Amount | 0.0 – 1.0 | 0.6 |
| `wobble` | Tape wobble | 0.0 – 1.0 | 0.4 |

## Install

Open **Azphalt Store** inside Guillotine, find *VHS Retro*, and tap **Install**. The effect is
applied to the selected clip.

To install manually, pack this directory as a `.azp` (a plain ZIP with `manifest.json` at the root)
and side-load it from the store's *Install from file* action.
